# Aspose.Cells Product Agent

This repository is maintained by the **Aspose.Cells Product Agent**.

The agent automatically:

1. Fetches categories and tasks from the **Task Browser Agent**
2. Requests code generation from the **Examples Super Agent**
3. Builds and validates the generated code
4. Applies automated fixes when required
5. Publishes validated examples into category folders
6. Creates pull requests for review

Only build-validated examples are published.

## Categories

Examples are organized by category folders.  
Each category contains an `agents.md` file listing the tasks implemented in that category.
